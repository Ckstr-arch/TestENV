# 🧪 Student exercise workspace

This folder contains learning instructions, not a deployable app or duplicate PHP services. Start with [the labs](../05-labs-and-exercises.md). Keep synthetic accounts in your own development instance and avoid recording secrets.

For each experiment create a private worksheet outside public webroot with: prediction, actual route/status, source call chain, row/state observed, discrepancy, next hypothesis and cleanup performed. Do not export entire SQL tables or browser HAR/session files as evidence. Temporary source edits belong only to the exact lines you personally change; restore those manually from your own saved patch.

The membership lifecycle, stale composer and booking-boundary labs need no new production source files. A proposed UX improvement requires human implementation/review and must not be counted as completed merely because these instructions exist.
