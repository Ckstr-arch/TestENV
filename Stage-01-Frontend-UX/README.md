# Stage 01 · Frontend and UX 🟢

Make the existing SportsHub interface understandable, usable and responsive. **Member A (TBD)** is a proposed responsibility, not an authorship award. This is Topic 3, one application; this folder is a teaching package, never a webroot.

## Your outcome

Explain how PHP emits the homepage DOM, how CSS lays it out, how JavaScript enhances real forms, and how keyboard/mobile users reach the same features. Then make one reviewed improvement that you personally understand.
